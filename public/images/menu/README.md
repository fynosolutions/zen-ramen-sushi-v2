# 菜单图片

把真实菜品图片按菜品 ID 命名，放在这个文件夹中。下一次构建部署会自动识别，不需要修改菜单数据或页面代码。

- 支持 `.webp`、`.jpg`、`.jpeg`、`.png`、`.avif`，每个 ID 只保留一个文件。
- 例如 `dinner-5-0.webp` 对应 Dinner → Special Roll → Crazy Yellowtail Roll。
- 完整菜名与文件名对照见 `docs/menu-photo-index.md`。
- 建议使用至少 800 × 800 像素的清晰图片，主体居中。缩略图统一正方形裁切；放大时显示完整图片。
- 换图时用同名文件替换；删除图片后重新构建，对应位置恢复浅暖灰占位。
- 同一道菜在不同菜单中的 ID 不同，可将同一张经过确认的照片分别保存为对应 ID。
- 只有实际存在的图片才会显示和支持放大；未提供图片的菜品保留无图标、无文字的浅暖灰色块。

仍然按新分支 → PR → 审核的流程上传。不要为了补图修改 `content/menus.json`。
